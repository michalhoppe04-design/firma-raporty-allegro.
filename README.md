# Firma — raporty Allegro

Wersja: 1.0.0

Aplikacja przeznaczona wyłącznie na potrzeby własnego konta
sprzedawcy Allegro.

Cel: odczyt ofert, zamówień, opłat i historii płatności
oraz przygotowywanie lokalnych zestawień sprzedażowych.

Zakres dostępu:
- allegro:api:sale:offers:read
- allegro:api:orders:read
- allegro:api:billing:read
- allegro:api:payments:read

Autoryzacja: OAuth 2.0 Device Flow.

Aplikacja jest w trakcie konfiguracji.
Nie edytuje ofert, nie wysyła wiadomości i nie wykonuje zwrotów.

Repozytorium zawiera wyłącznie dokumentację.
Nie zawiera kluczy, tokenów ani danych klientów.
